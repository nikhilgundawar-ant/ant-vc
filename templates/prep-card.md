# Template: prep card

Chat: five lines. Home: the full card.

| Field | Content |
| --- | --- |
| who | Lead attendee, company, and stage with day count ("Term sheet, day 5") |
| attendees | Name, title, company, relationship strength, last touch |
| history | Last three interactions: date, type, subject, link |
| open_commitments | Both directions, with due dates and links |
| deal | Stage, days in stage of dwell, next step, link |
| colleagues | Who at the firm met them, and when |
| questions | Exactly three, each ends with a question mark |
| finding | The one thing to know ("Deck promised 09 Oct, still open") |
| empathy_map_url | Link when one exists |
| source_url | The calendar event |
