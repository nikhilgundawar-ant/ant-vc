# Brand rules for ant-vc

One name everywhere, so it sticks.

| Where | Write it as |
| --- | --- |
| Product name in any sentence a user reads | **ant.** (lowercase, with the full stop), or **ant. for VCs** in a title |
| Plugin id, repository, file names, marketplace entry | `ant-vc` (the repo is `nikhilgundawar-ant/ant-vc`, the file is `ant-vc.plugin`) |
| The page | ant. Home |
| Scheduled tasks | "ant." and "ant. weekend" |
| Scheduled-run marker | `[ant-vc-scheduled-run]` |
| Wordmark | "ant." in Nunito 800, beside the Anthill mark (24 px) |

- Never write "Ant." with a capital, "Ant", "ANT" or "ant.." (no double full stop when a sentence ends on the name).
- Never use the old name, Instinct, in anything a user reads.
- Code folders (`engine/instinct/`) and saved keys keep their old names on purpose: renaming them would break installs and gains nothing a user sees.
